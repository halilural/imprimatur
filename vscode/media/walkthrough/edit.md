# See the agent's first edit

In this repo, ask Claude Code to change a Markdown file, for example:

> Add a short "Contributing" section to README.md.

The edit stays marked in the editor and in the Markdown preview until you accept it, as tracked changes. Committing does not clear the marks.

**Agent changes** lists every edit the agent made, with what it changed and why. You accept edits there or in the editor.
