# Keep tasks and records

The agent keeps each task's to-dos, decisions, questions and notes in Imprimatur through its MCP tools. A task is a GitHub issue (#58) or a Jira key.

- **👉** marks where work stopped, so the next session starts there.
- **Waiting on you** gathers what the agent needs from you: questions, steps to do, things to check by eye.
- **Architecture**, **Product** and **Glossary** are living documents. They are written from the decisions, and every section is linked to the records behind it.
