# Sources

This skill adapts ideas from [mattpocock/skills](https://github.com/mattpocock/skills), at commit
`4ae2317ddb22`, read on 2026-11-09 (Imprimatur #172):

| Skill | Taken |
| --- | --- |
| `engineering/to-spec` | synthesize instead of interviewing; the spec's parts (problem, user stories, implementation and testing decisions, out of scope); decisions rather than file paths and code |
| `productivity/grilling` (via `grill-with-docs`) | numbered rounds over the decisions whose prerequisites are settled, each with a recommended answer worded so "yes" accepts it; facts found by a sub-agent, never asked of the user |
| `engineering/domain-modeling` (via `grill-with-docs`) | glossary terms written as soon as they settle; an ADR only when the choice is hard to reverse, surprising without context and the result of a real trade-off |
| `engineering/research` | a background agent with a fresh context, primary sources, each claim cited |
